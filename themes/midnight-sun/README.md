# Midnight Sun

Navy-tinted dark with a sunshine-yellow accent, shared across apps.

- **Edit** `palette.json`, then run `./build.py` to regenerate every app's file.
- **Logseq**: paste `logseq.css` into Settings → General → Custom theme → Edit custom.css (dark mode).
- **iTerm2**: `iterm-profile.json` is a dynamic profile, symlinked by `link.sh` and set as the default profile.
- **VS Code**: `vscode/` is a local theme extension, symlinked into `~/.vscode/extensions` by `link.sh`.
- **Linear**: enter the values in `linear.txt` under Settings → Preferences → Interface theme → Custom.
- **iPhone icons**: `build.py` also runs `icons.py`. For each app in `icons.json` it draws a navy tile with a sun-yellow glyph (Simple Icons logo, or Phosphor for Apple's apps and apps without one) and signs a Shortcuts file that opens the app. Output goes to `ios/` (git-ignored), and the PNGs are copied to iCloud Drive → `Midnight Sun icons`. Needs `resvg` (Brewfile) and macOS's `shortcuts` command.
  - **New app:** add it to `icons.json` (its bundle id is in `https://itunes.apple.com/lookup?bundleId=…` results, or search by name), run `./build.py`, open `ios/shortcuts/<App>.shortcut` on the Mac and click Add Shortcut. It syncs to the phone through iCloud.
  - **On the phone, once per app:** Shortcuts → the shortcut's ⋯ → its name → Add to Home Screen → Image → Choose File → `Midnight Sun icons/<App>.png` → Add. Then move the real app off the home screen (it stays in the App Library).
  - **Folder stand-in:** iOS folders can't have their own icon, so a `menus` entry makes one icon whose shortcut shows a menu of apps (`bundle`) or websites (`url`; a home-screen web bookmark can't be opened by a shortcut, only its site in the browser). Private apps and menus go in `~/.config/midnight-sun/icons.local.json` (same format, backed up in Bitwarden), not in this repo.
  - **Palette change:** `./build.py` rewrites the PNGs, but the phone keeps the image each icon was given, so every icon has to be added again (the same steps as "On the phone, once per app", and the runbook below). Themed icons never show notification badges.
  - **Custom glyph:** for an app with no usable logo, draw a single-colour SVG (viewBox 0 0 100 100, `fill="currentColor"`, cut-outs through a `<mask>`) in `glyphs/custom/<name>.svg` and set `"glyph": "custom:<name>"` in `icons.json` (the Firefox raccoon and the Hue candle are the examples). It is drawn at 66% of the tile like Phosphor glyphs.
  - **Plates (the home-screen look since 2026-11-08):** an app whose icon is a full-tile drawing rather than a glyph on navy sets `"glyph": "plate:<name>"`, and `glyphs/plates/<name>.svg` is rendered as is (it carries its own tile colour and lines; viewBox 0 0 120 120, square, no rounded corners). These are the engraved "magic diagram" icons: brass line work on a tile tinted by element (midnight, plum, oxblood or deep teal). His own apps (Ledger, Grimoire, Forge, Coinbox, Hoard) and the Practice web app carry the same plates in their own icon files. The menu once called Gay is now Courting (`plate:rings`, in the local file).
  - **Keeping plates in line with the plate-icons skill:** `glyphs/plates/elements.json` says which element (fire, earth, air, water) each plate has, and each element's tile and second colour. `./plates.py lint` checks every plate against what a script can see (canvas, tile, colours, the whole outer ring); `retile` moves plates to their element's colours; `markers` redraws each plate's top marker (kept in `<g id="marker">`) as its element's; `sheet out.png --ref HEAD` draws a before-and-after contact sheet by element at 180, 60 and 29 px; `mac` redraws `mac/<name>.png` from the plates. After a skill change: edit `elements.json` (and the marker shapes in `plates.py`), run `retile`, `markers`, `lint`, look at the sheet, then `mac`, `./build.py` and `export`. `export` writes each plate into his own apps' icon files (icon sets, web icons, the app repo's copy of the plate), listed under `apps` in `elements.json` as paths below `~/Projects`; each app is then committed, built and deployed its own way. Shapes and ring styles are still redrawn by hand, plate by plate. Hoard's iPhone and Apple TV icon files are other shapes (an Icon Composer layer, layered TV icon, Top Shelf stills): `hoard_apple.py` draws those. `rollout.sh [name ...]` then builds and installs the apps (web, Mac, iPhone, Apple TV); it ships each repo's working tree, so check `git status` there first.
  - **Web app icon:** an entry with `"webapp": true` (in `~/.config/midnight-sun/icons.local.json`, e.g. a personal web app) gets only the picture and no shortcut. Copy the PNG into the app's own icon files (the page's `apple-touch-icon`), open the app in Safari and use Share → Add to Home Screen, so it keeps opening as a standalone web app (a shortcut would open it in the default browser). Deleting the old home-screen icon of a web app also deletes its local storage, so check for unsent drafts first.
  - **Why Shortcuts icons and not a Web Clip profile (tried 2026-10-07):** an unsigned Web Clip profile installs on iOS (Settings → Profile Downloaded → Install, passcode) and installing it again with a new PNG replaces the icons in place, which would make a palette change one install. But tapping a web clip always shows a blank full-screen page before the app opens: with a `shortcuts://run-shortcut` URL it goes black, then Shortcuts, then the app; with the app's own scheme (`linear://`, `logseq://`) the Shortcuts hop goes away and the black page stays. Turning full-screen off and setting `TargetApplicationBundleIdentifier` did not help either (the clip opened Chrome). A Shortcuts "Add to Home Screen" icon runs the shortcut in the background and opens the app straight away, with only a small indicator. Not tried: iOS 18's Customize → Tinted icons, which recolors the real app icons with no transition at all (no custom glyphs). A self-hosted MDM would update icons silently, but Apple only issues MDM push certificates to organisations, not for personal devices.
  - **Doing the per-icon add and swap through iPhone Mirroring (what worked, 2026-10-06 and 07):**
    - Setup: the mirroring window must be on a normal desktop Space, not a full-screen one. Background clicks don't register in it, so use full-screen control. It only connects while the iPhone is locked ("iPhone in Use" otherwise), so lock the phone after each passcode step. `⌘1` is Home Screen and `⌘3` is Spotlight. Passcodes are typed by hand, never by Claude.
    - Add one icon: Shortcuts → the shortcut's ⋯ → its name → Add to Home Screen → Image → Choose File, then search the file picker for the app name and tap the `Midnight Sun…` scope chip so only these PNGs match (an app's own folder, such as Firefox's, can match the name). Check the preview shows the right icon and label, then Add. The icon lands on the last home-screen page. The first tap on a folder only selects it; tap again to open it.
    - Move and remove icons: long-press empty space to enter edit mode, swipe pages by dragging on a gap between rows, remove an icon with its minus. A quick drag (`left_click_drag`) lifts an icon and works on the dock and within a page. It can't hold at a page edge, and a held mouse-down just drags the page, so moving an icon to another page has to be done on the phone by hand. Deleting an icon makes the rest of the page reflow, and widgets can float up.
    - What worked on 2026-11-26 (replaces the limits above where they differ): `type` drops characters, so send text as single key presses. A slow drag does move icons and widgets, across pages too: mouse down, wait 0.7 s, move a little straight up or down first (a sideways first move swipes the page, and with no wait it can drag the Mac window), then move to the target, wait 1.5 s, mouse up. To change page, hold at the screen edge 1.2 s for one page; 2 s is two pages, and a long hold runs on into Today View (widgets) or the App Library. Hovering on an icon makes a folder; hover between icons to insert. Order that avoids a mess: add all the new icons, delete the old ones, then on each page make room before dropping anything, because a drop on a full page pushes widgets to the next page. Only icons actually on the home screen need re-adding. Tap Done before anything in the App Library (its badges delete apps).
    - Read every delete dialog before confirming: "Delete Bookmark" is one of these icons, but a dock icon can be a real app (the dialog then offers "Delete App"; cancel it). Avoid dragging over the Files list: it opens a context menu.

## Mac app icons

`mac/` holds the Mac app icons: `firefox.png` and `claude.png` are the same engraved plates as the phone (`glyphs/plates/`), drawn on Apple's Mac grid (an 824px rounded tile, radius 185, centred on a 1024 canvas with a soft shadow); `iterm2.png` is still the athame glyph. Discord, Linear, Logseq, Signal, Spotify, Sync, Google Chrome and VS Code have plates too (apps installed by root, such as Bitwarden, Fantastical, Immich, Slack and Tailscale, would need `sudo` for `fileicon`, so they keep their own icons). His own Mac apps (Ledger, Grimoire, Forge, Coinbox, Hoard) carry their plates in their own Mac icon sets. Messages and Music are system apps on the sealed system volume, so they keep Apple's icons. An app update replaces the app and wipes its custom icon, so a LaunchAgent (`com.nicholai.midnight-sun-icons`, installed by `link.sh`) runs `mac/apply-icons.sh` when an app path changes, at login and hourly. It uses `fileicon` (Brewfile), skips apps that aren't installed or already have the icon from the current PNG (a hash is kept in `~/Library/Application Support/midnight-sun/icons/`), and logs to `~/Library/Logs/midnight-sun-icons.log`. `mac/test-apply-icons.sh` exits 0 only when every installed app has its icon.

- **Add an app:** put its PNG in `mac/`, add a line `/Applications/<App>.app "$HERE/<name>.png"` to `ICONS` in `apply-icons.sh`, add the app path to `WatchPaths` in the plist, run `./link.sh` (relinks the plist) and `launchctl kickstart gui/$UID/com.nicholai.midnight-sun-icons`. If the plist changed, `launchctl bootout gui/$UID/com.nicholai.midnight-sun-icons` first so `link.sh` reloads it.
- **Caveats:** `codesign --verify --strict` reports "Disallowed xattr com.apple.FinderInfo" for an app with a custom icon (plain `codesign --verify` and `spctl` still pass). The Dock may keep showing the old icon until it restarts (`killall Dock`).
