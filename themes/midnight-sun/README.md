# Midnight Sun

Navy-tinted dark with a sunshine-yellow accent, shared across apps.

- **Edit** `palette.json`, then run `./build.py` to regenerate every app's file.
- **Logseq**: paste `logseq.css` into Settings → General → Custom theme → Edit custom.css (dark mode).
- **iTerm2**: `iterm-profile.json` is a dynamic profile, symlinked by `link.sh` and set as the default profile.
- **VS Code**: `vscode/` is a local theme extension, symlinked into `~/.vscode/extensions` by `link.sh`.
- **Linear**: enter the values in `linear.txt` under Settings → Preferences → Interface theme → Custom.
- **iPhone icons**: `build.py` also runs `icons.py`. For each app in `icons.json` it draws a navy tile with a sun-yellow glyph (Simple Icons logo, or Phosphor for Apple's apps and apps without one) and signs a Shortcuts file that opens the app. Output goes to `ios/` (git-ignored), and the PNGs are copied to iCloud Drive → `Midnight Sun icons`. Needs `resvg` (Brewfile) and macOS's `shortcuts` command.
  - **New app:** add it to `icons.json` (its bundle id is in `https://itunes.apple.com/lookup?bundleId=…` results, or search by name), run `./build.py`, open `ios/shortcuts/<App>.shortcut` on the Mac and click Add Shortcut. It syncs to the phone through iCloud.
  - **On the phone, once per app:** Shortcuts → the shortcut's ⋯ → its name → Add to Home Screen → Image → Choose File → `Midnight Sun icons/<App>.png` → Add. Then move the real app off the home screen (it stays in the App Library).
  - **Folder stand-in:** iOS folders can't have their own icon, so a `menus` entry makes one icon whose shortcut shows a menu of apps (`bundle`) or websites (`url`; a home-screen web bookmark can't be opened by a shortcut, only its site in the browser). Private apps and menus go in `~/.config/midnight-sun/icons.local.json` (same format, backed up in Bitwarden), not in this repo.
  - **Palette change:** `./build.py` rewrites the PNGs, but the phone keeps the image it was given, so each icon has to be added again. Themed icons never show notification badges.
  - **Custom glyph:** for an app with no usable logo, draw a single-colour SVG (viewBox 0 0 100 100, `fill="currentColor"`, cut-outs through a `<mask>`) in `glyphs/custom/<name>.svg` and set `"glyph": "custom:<name>"` in `icons.json` (the Firefox raccoon is the example). It is drawn at 66% of the tile like Phosphor glyphs.
  - **Profile route (untested):** `build.py` also writes Web Clip configuration profiles to `ios/profiles/` (`midnight-sun-all.mobileconfig`, and one per icon under `single/`) and copies them to iCloud Drive → `Midnight Sun icons/profiles`. Each icon is a web clip that opens `shortcuts://run-shortcut?name=<App>` with the Midnight Sun PNG. Installing the profile by hand (Settings → Profile Downloaded → Install) is meant to replace every icon in one go, so a palette change needs one install instead of re-adding each icon. Try a `single/` profile first: it hasn't been confirmed that the web clip launches the shortcut cleanly, or that iOS accepts it unsigned. Remove the old icons first, or each app gets two.
  - **Doing the per-icon swap through iPhone Mirroring (what worked, 2026-10-06):** the mirroring window must be on a normal desktop Space, not a full-screen one (`app_bring_to_current_space` refuses otherwise). Background clicks don't register in it, so use full-screen control. `⌘1` is Home Screen (View → Spotlight is in the same menu). Open Shortcuts, tap the shortcut's ⋯, tap its name, then Add to Home Screen → Image → Choose File → iCloud Drive → `Midnight Sun icons`, check the preview thumbnail matches the new design, then Add. The icon lands alone on the last home-screen page. Long-press the page to enter edit mode (a quick drag does that too), swipe pages by dragging on a gap between rows, remove the old icon with its minus (the dialog says "Delete Bookmark" and only removes that icon), drag the new one into its place and tap Done. Avoid dragging over the file list: it opens a context menu.
  - A self-hosted MDM would update them silently, but Apple only issues MDM push certificates to organisations, not for personal devices.
